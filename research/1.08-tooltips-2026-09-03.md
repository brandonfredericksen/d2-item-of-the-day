# 1.08 tooltips, transcribed 2026-09-03

Transcribed from screenshots the user pasted into a Claude Code session. The image
files could not be saved: the desktop app did not write them to `.cp-images/`, so the
backup hook had nothing to copy and nothing reached
`research/reference-screenshots/`. These transcriptions are all that survived. If the
originals turn up, file them properly and add `proof:` paths to the cards.

Reading caveat: in the game font a 5 looks like a 6. Every number below has been read
with that in mind and cross-checked against the Moving Caravan 1.07/1.08 stat table
where that table covers the item.

---

## The Grandfather (Colossus Blade)

    The Grandfather
    Colossus Blade
    One-Hand Damage: 62 to 409
    Two-Hand Damage: 145 to 534
    Required Dexterity: 110
    Required Strength: 189
    Required Level: 81
    Sword Class - Fast Attack Speed
    Indestructible
    +150% Enhanced Damage
    +247 to Maximum Damage (Based on Character Level)
    150% Bonus to Attack Rating
    +20 to Strength
    +20 to Dexterity
    +175 to Life
    Increase Maximum Life 25%
    Increase Maximum Mana 25%
    Socketed (1)

Settles the question that got this card deleted and then restored. The life block is
real. So is the 150% attack rating bonus, which the modern sword has at 50%. The
per-level max damage was already there in 1.08, so 1.09 did not add it, it only took
the life block away. +247 puts the character at level 99.

## Highlord's Wrath (Amulet)

    Highlord's Wrath
    Amulet
    Required Level: 65
    +1 to All Skills
    +30% Faster Run/Walk
    Adds 5-20 lightning damage
    37% Deadly Strike (Based on Character Level)
    Lightning Resist +35%

It HAS deadly strike. The Moving Caravan table omits that line, and its spoiler is
titled "not done", so treat that table as incomplete rather than wrong. The real
difference from the modern amulet is the faster run in place of 20% attack speed,
plus the narrower 5-20 lightning damage and no attacker-takes-lightning line.

## Raven Frost (Ring)

    Raven Frost
    Ring
    Required Level: 45
    4% Chance to cast level 5 Frost Nova when struck
    Adds 15-25 cold damage
    Cold Resist +35%

No dexterity, no mana, no attacker-takes-damage. The modern ring has all three, and
the dex is the line everyone buys it for. Matches the Moving Caravan table. Not carded
yet, and it is the cleanest example on this page of a 1.08 unique being plainly worse.
