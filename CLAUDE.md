# CLAUDE.md

## Pasted images

When the user pastes a Diablo 2 item screenshot, treat it as source material worth keeping. Read it, identify the item, and follow the `save-item-screenshot` skill to file it under `research/reference-screenshots/` named after the item. Do this without being asked.

Site renders, design references, and debug captures are not item screenshots. Leave those where they are.

Never delete anything in `.cp-images/` or `.cp-backup/`.
